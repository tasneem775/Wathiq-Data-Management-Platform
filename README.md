# وثيق | Wathiq

نظام عربي ذكي لإدارة الامتثال والحوكمة لمتطلبات المؤشر الوطني للبيانات NDI.

## فكرة المشروع

يساعد نظام وثيق الجهات الحكومية على متابعة مستوى الامتثال والنضج بشكل مستمر طوال السنة، من خلال تحليل الأدلة والوثائق، وربطها بمتطلبات NDI، واكتشاف الفجوات، وتوليد التوصيات والتقارير الرسمية.

## اللغة

المشروع Arabic-First:

- واجهة عربية
- RTL
- تقارير عربية
- توصيات عربية
- تخزين النصوص بصيغة UTF-8

## دعم العربية

يتم استخدام:

- arabic-reshaper
- python-bidi

فقط عند توليد:

- PDF
- Word
- PowerPoint

ولا يتم استخدامها داخل قاعدة البيانات أو ChromaDB أو RAG أو ملفات JSON.
